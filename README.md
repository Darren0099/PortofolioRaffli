# Raffli Portfolio — PHP-era Personal Website

Versi awal website portofolio **Al-man Raffli Saputra** yang digunakan untuk mengeksplorasi desain halaman pribadi, informasi pendidikan, pengalaman, keterampilan, dan proyek sebelum migrasi ke portofolio modern.

## Bagian website

- Profil pribadi dan informasi kontak.
- Perjalanan pendidikan serta pengalaman organisasi.
- Layanan dan kemampuan yang ditampilkan sebagai kartu.
- **Theme switcher** dengan beberapa variasi warna.
- **Mode terang/gelap** melalui kontrol tampilan.
- Halaman satu berkas utama dengan navigasi ke section-section portofolio.

## Teknologi

**HTML**, **CSS**, **PHP sebagai ekstensi entry point**, **Bootstrap 5**, serta ikon **Font Awesome** dan **Bootstrap Icons**. Implementasi terpusat pada `index.php` dan `assets/css/styles.css`.

## Nilai proyek

Proyek ini mendokumentasikan eksperimen **responsive personal branding dan tampilan yang dapat dikustomisasi**. Sebagian data profil dan riwayatnya merupakan snapshot lama.

**Versi portofolio terbaru:** [Raffli-dev](https://github.com/Darren0099/Raffli-dev).
